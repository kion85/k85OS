## v7.5 - 2026-10-02

### Package Manager (Tools -> Package Manager)

- Новый пункт **Tools -> Package Manager** (файл `main/apps/tools/package_manager.cpp`): установка пакетов по WiFi прямо с устройства. Три раздела:
  - **Games** - игры из репозитория apps_k85os (релиз с тегом `app`).
  - **Themes** - UEFI/BIOS-темы `.thm` из `apps_k85os/uefi`. Уже скачанные помечаются `[installed]`, применяются через BIOS -> Update UEFI theme.
  - **Firmware** - прошивки из последнего релиза k85OS (список `.bin` + подпись).
- Игры и прошивки записываются в свободный OTA-слот с подтверждением. Подпись Ed25519 обязательна: пакеты без подписи отклоняются. Имя установленного пакета запоминается только после успешной прошивки.
- Запуск установленного образа: **BIOS -> System tools -> Slots & partitions -> Boot other slot**.
- Темы качаются через временный файл с проверкой размера и имени (защита от обрыва загрузки и подмены пути). Списки пакетов хранятся в PSRAM, а не в статической RAM.

### Скрипты, планировщик, FTP

- **Автозапуск**: `/littlefs/startup.sh` выполняется при загрузке. Поддерживаются все команды shell и новые: `echo`, `set NAME=value` (переменные `$NAME`, встроенные `$IP`, `$SSID`), `alias` / `unalias`, `sleep N`, `sh файл`, `exit`, `reboot`, комментарии `#`.
- **Планировщик (cron)**: файл `/littlefs/crontab`, формат `мин час день месяц день_недели команда` (`*`, `*/N`, диапазоны, списки). Журнал выполнения в `/littlefs/cron.log`. Задания идут после синхронизации времени по NTP. Команда `cron on|off|reload|list`.
- **FTP-сервер**: **Tools -> FTP Server** (также Tools -> Services). Копирование файлов ПК <-> устройство (скачивание, загрузка, удаление, переименование, папки). Корень `/littlefs`, только сеть STA (через хотспот недоступен), passive-режим, один клиент. Логин задаётся командой `ftppass <user> <password>` в Terminal/SSH, пароль хранится хэшем. Загрузка идёт во временный файл, автоотключение через 15 минут без клиентов, автозапуск включается в Services.
- **Services** дополнен пунктами FTP Server, FTP autostart, Startup script, Scheduler (cron).
- **Защита**: ключ SSH, конфиг, `k85_svc.cfg` и бэкап конфига недоступны ни через shell (`cat`), ни через FTP. После краша, watchdog или brownout автозапуск пропускается на одну загрузку, чтобы кривой скрипт не вызвал бесконечный перезапуск.

### BIOS: System tools (новый пункт)

- **Hardware monitor** - частота CPU, температура чипа, свободная RAM и PSRAM, батарея, WiFi RSSI, аптайм (обновление раз в секунду).
- **Automation / safe** - включение/выключение Startup script, Scheduler, FTP autostart и «Disable all autostart».
- **Backup config / Restore config** - копия конфига на устройстве и восстановление с перезагрузкой.
- **Signature info** - отпечаток (SHA-256) открытого ключа Ed25519 для проверки подписи прошивок.
- **Diagnostics** - тесты дисплея (цвета, полосы, градиент), кнопок, динамика, IMU, RTC и PSRAM (проверка свободной памяти тремя шаблонами).
- **Slots & partitions** - таблица разделов, версия и дата сборки каждого OTA-слота, запуск другого слота (**Boot other slot**).
- **Security status** - только чтение: шифрование флеша, secure boot, JTAG, ROM-загрузчик, подпись OTA, пароль BIOS.
- **BIOS password** - пароль на вход в BIOS (PBKDF2-HMAC-SHA256, как у экрана блокировки). Задержка после неверной попытки, 5 неудач подряд закрывают BIOS.

### BIOS: CPU frequency

- Новая строка **CPU frequency** (только в BIOS): `OS` / `80 MHz` / `160 MHz` / `240 MHz`.
- Фиксированное значение из BIOS имеет приоритет: настройка частоты в ОС игнорируется. При выборе `OS` частотой управляет ОС (её значение сохраняется и не затирается).

### Игры

- Добавлены исходники игр **Pong** и **Memory Match** (пункт Games).

### Заметки

- FTP передаёт пароль и файлы без шифрования - используйте только в доверенной домашней сети.
- Пароль BIOS защищает вход в BIOS-меню, но не устройство целиком.

### Прошивка (ESP32-S3, 8 MB, dio, 80 MHz)

python -m esptool --chip esp32s3 -b 460800 write_flash 0x0 k85OS_7.5.bin




## v7.0 - 2026-09-18

### Клавиатура (текстовый ввод)
- Новая настройка "Keyboard nav" (Settings): навигация по экранной клавиатуре либо классически кнопками (A/B, как раньше), либо наклоном устройства (IMU tilt) - наклон двигает выделение по столбцам/строкам, B по-прежнему выбирает символ.

### Загрузчик / BIOS
- 4 стиля загрузочного меню на выбор (BIOS -> Boot loader style): k85OS Boot Menu (прежний, по умолчанию), k85OS BIOS Boot (строгий текстовый, диски подписаны Flash1-4 с расшифровкой в скобках), GRUB-style, rEFInd-style (горизонтальная галерея).
- Новый экран "kernel panic": при загрузке после реального краша/watchdog/brownout (на основе esp_reset_reason) показывается причина сбоя, A+B или 15с - продолжить обычную загрузку. Тестируется командой `panic-test` в шелле.

### Internet SDR / Web Radio
- Починен звук: KiwiSDR присылает PCM-сэмплы в big-endian, устройство читало их как little-endian - отсюда были тишина/шум вместо голоса.
- kiwisdr_client.cpp переведён на выделенный фоновый поток для всех вызовов esp_websocket_client_* (раньше UI-поток слал команды параллельно с приёмом, из-за чего иногда рвалось соединение - "Could not lock ws-client").
- Спектр в Internet SDR теперь градиентный и яркий (тёмно-синий -> зелёный -> жёлтый -> белый), с "шапкой" на каждой полоске.
- Web Radio: громкость сессии теперь явно выставляется (раньше не трогалась вообще).

### Навигация в меню
- Главное меню: удержание A - непрерывная прокрутка списка назад (одиночный тап - как раньше, на 1 пункт вперёд).
- Tools/Apps/WiFi/Games/Clock: двойной тап B - мгновенный выход в главное меню (одиночный B по-прежнему открывает пункт).

### Новые инструменты (Tools)
- Disk Cleanup: топ-15 самых больших файлов на LittleFS, удаление в один клик.
- Services: статус SSH Server, автоподключение MQTT при загрузке, переключаемая фоновая проверка OTA (Hotspot autostart - пока недоступен).
- Команда `ps`/`htop` (список задач FreeRTOS) - работает в Terminal, Web Terminal и по SSH.

### Прочее
- SSH Server теперь реально автостартует при загрузке, если включён в BIOS (раньше поднимался только в момент переключения тумблера, не переживал перезагрузку).
- Экран блокировки: после 85 секунд простоя запускается скринсейвер - буквы "k85os" разлетаются по экрану под тихую мелодию (~50% громкости); любая кнопка возвращает обычный экран блокировки.
