
## v7.0 - 2026-09-18

### Клавиатура (текстовый ввод)
- Новая настройка "Keyboard nav" (Settings): навигация по экранной клавиатуре либо классически кнопками (A/B, как раньше), либо наклоном устройства (IMU tilt) - наклон двигает выделение по столбцам/строкам, B по-прежнему выбирает символ.

### Загрузчик / BIOS
- 4 стиля загрузочного меню на выбор (BIOS -> Boot loader style): k85OS Boot Menu (прежний, по умолчанию), k85OS BIOS Boot (строгий текстовый, диски подписаны Flash1-4 с расшифровкой в скобках), GRUB-style, rEFInd-style (горизонтальная галерея).
- Новый экран "kernel panic": при загрузке после реального краша/watchdog/brownout (на основе esp_reset_reason) показывается причина сбоя, A+B или 15с - продолжить обычную загрузку. Тестируется командой `panic-test` в шелле.

### Internet SDR / Web Radio
- Починен звук: KiwiSDR присылает PCM-сэмплы в big-endian, устройство читало их как little-endian - отсюда были тишина/шум вместо голоса.
- kiwisdr_client.cpp переведён на выделенный фоновый поток для всех вызовов esp_websocket_client_* (раньше UI-поток слал команды параллельно с приёмом, из-за чего иногда рвалось соединение - "Could not lock ws-client").
- Спектр в Internet SDR теперь градиентный и яркий (тёмно-синий -> зелёный -> жёлтый -> белый), с "шапкой" на каждой полоске.
- Web Radio: громкость сессии теперь явно выставляется (раньше не трогалась вообще).

### Навигация в меню
- Главное меню: удержание A - непрерывная прокрутка списка назад (одиночный тап - как раньше, на 1 пункт вперёд).
- Tools/Apps/WiFi/Games/Clock: двойной тап B - мгновенный выход в главное меню (одиночный B по-прежнему открывает пункт).

### Новые инструменты (Tools)
- Disk Cleanup: топ-15 самых больших файлов на LittleFS, удаление в один клик.
- Services: статус SSH Server, автоподключение MQTT при загрузке, переключаемая фоновая проверка OTA (Hotspot autostart - пока недоступен).
- Команда `ps`/`htop` (список задач FreeRTOS) - работает в Terminal, Web Terminal и по SSH.

### Прочее
- SSH Server теперь реально автостартует при загрузке, если включён в BIOS (раньше поднимался только в момент переключения тумблера, не переживал перезагрузку).
- Экран блокировки: после 85 секунд простоя запускается скринсейвер - буквы "k85os" разлетаются по экрану под тихую мелодию (~50% громкости); любая кнопка возвращает обычный экран блокировки.

### Прошивка (ESP32-S3, 8 MB, dio, 80 MHz)
python -m esptool --chip esp32s3 -b 460800 write_flash 0x0 k85OS_7.0.bin
